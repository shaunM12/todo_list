# Todo List

A simple command-line todo list app written in Python.

## Features

- Add a task to an in-memory list
- Print all tasks with numeric positions
- Delete a task by its list number
- Save tasks to `todos.csv`
- Load tasks from `todos.csv` back into memory

## Files

- `todo_list.py` — main program
- `todos.csv` — saved tasks

## How to run

From this folder:

```bash
python3 todo_list.py
